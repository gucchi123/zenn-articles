個人プロジェクトで、YouTube のショート動画を毎日自動で公開している。動画ごとに、自分のチャンネルから案内のコメントを1件付けて固定する。説明欄は「もっと見る」を開かないと読まれないが、固定コメントはコメント欄の一番上に出る。押してもらえる場所として、いちばん効くと考えていた。

コメントが付いているかは、YouTube Data API で確かめていた。`commentThreads.list` で自分のコメントが返ってくれば「付いている」。そのはずだった。

## 気づいたきっかけ

ある動画で、固定の作業をしようと視聴ページを開いた。ところが、API では返ってくる自分のコメントが、ページのどこにも無かった。

一度きりの表示の揺れかもしれない。そう考えて、再生数の多い上位20本を、**ログインしていないブラウザ**で1本ずつ開いて数えた。

| 確かめ方 | 結果 |
|---|---|
| API（`moderationStatus=published`） | 自分のコメント917件。保留0件・スパム判定0件 |
| ログアウトした画面で上位20本 | 17本は見える。**3本はコメント欄が0件** |

![API の確認とログアウト画面の確認の違い](/images/api-says-public-but-comment-invisible.png)

3本は API 上は公開で、保留にもスパムにも入っていない。それなのに、外からは1件も見えない。上位20本のうち15%にあたる。再生数の多い順に並べた上位なので、いちばん人に見られている面で、案内が消えていたことになる。

## 最初の「0件」を疑った

最初の一巡では、0件の動画は5本だった。コメント欄は遅れて読み込まれるので、待ち時間が足りないだけかもしれない。待ち時間を倍にして開き直すと、5本のうち2本は見えた。残る3本は何度開いても0件だった。

「見えない」と判定する前に、**読み込みが遅いだけの可能性を先に消す**。これをしないと、表示の遅れを問題として数えてしまう。

## 文面のせいでもなかった

見えない3本と見えている17本のコメントは、ほぼ同じ文面だった。リンクの数も同じ。投稿した日も同じ週のものがある。文面で弾かれたのなら、見えている側にも同じことが起きるはずだ。

チャンネルの持ち主としてログインした画面で開いても、見えない古いコメントは表示されなかった。届いたのは API の上だけで、表示からは外れている。そういう状態に見える。

YouTube 側で何が起きているのかは、外からは分からない。分かっているのは、「API で返る」と「人に見える」は同じではない、ということだけだ。

## やったこと

1. 見えない3本に、同じ趣旨のコメントを新しく入れ直した（古いものは消していない）
2. 持ち主の画面で固定した
3. **ログアウトした画面で開き直し**、3本とも固定された状態で見えることを確かめた

確かめる道具も残した。上位の動画をログアウトした画面で開いて、自分のコメントが見えるか、固定されているかを1行ずつ出すだけのスクリプトだ。

```js
// ログアウトしたブラウザで開き、自分のコメントが見えるかを数える（読むだけ）
for (const vid of videoIds) {
  await page.goto(`https://www.youtube.com/watch?v=${vid}`, { waitUntil: 'commit' });
  await page.waitForTimeout(12000);
  for (let k = 0; k < 10; k++) { await page.mouse.wheel(0, 700); await page.waitForTimeout(2500); }
  const r = await page.evaluate(() => {
    const th = [...document.querySelectorAll('ytd-comment-thread-renderer')];
    const own = th.filter(t => t.innerText.includes(MY_MARKER));
    return { n: th.length, own: own.length, pinned: own.some(t => /固定|Pinned/.test(t.innerText)) };
  });
  console.log(vid, JSON.stringify(r));
}
```

## 学んだこと

**確かめ方は、届けたい相手の画面に合わせる。** API は「自分が書いたものが保存されているか」を答えてくれる。だが「他人に見えているか」は答えてくれない。今回ほしかったのは後者で、それはログアウトした画面でしか確かめられなかった。

以前にも、自分の入力欄を読んで「投稿できた」と判定していた失敗があった。**確かめる場所が、書いた側に近すぎる**という点で、今回も同じ型だ。成功の確認は、読む人の側に寄せるほど信用できる。

もう一つは、**0件を見たら、まず読み込みの遅れを消す**こと。最初の一巡の5本をそのまま「見えない」と数えていたら、直す必要のない2本まで触るところだった。

この先は、上位の動画をときどきログアウトした画面で見回るつもりだ。入れ直したコメントがまた見えなくなるのか。見えなくなるなら、どれくらいの日数で起きるのか。そこはまだ分かっていない。
