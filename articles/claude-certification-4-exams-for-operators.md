Anthropic の Claude 公式認定資格について、10月15日に「日本語で受験できるようになった」という告知が SNS で流れてきた。気になって、公式のページと4試験ぶんの試験ガイド（2026年7月版の PDF）を読んだ。

先に結論を書くと、こうなる。

- **個人では受けられない。** 受験できるのは Claude Partner Network（CPN）に加盟している組織の社員だけで、会社のメールでサインインする
- 4種類のうち、Claude Code やエージェントを毎日動かしている人にいちばん近いのは **Architect – Foundations**。出題の重心がそのまま「運用で踏む判断」になっている
- 日本語受験は、10月16日時点の公式 FAQ ではまだ「英語のみ」と書かれている。申込画面で確かめるのが確実

![Claude 公式認定4種の比較](/images/claude-certification-4-exams-for-operators.png)

## 4種類の早見表

| 試験 | コード | 問題数 | 受験料 | 想定する人 |
|---|---|---|---|---|
| Associate – Foundations | CCAO-F | 60 | $99 | 業務で Claude を使う人。開発経験は不要 |
| Developer – Foundations | CCDV-F | 53 | $125 | Claude でアプリやエージェントを作るエンジニア |
| Architect – Foundations | CCAR-F | 60 | $125 | 本番システムを設計・実装する人 |
| Architect – Professional | CCAR-P | 63 | $175 | 上級の設計者・技術リード |

共通のルールは次のとおり。

- 120分（受付などを含めて約135分）、択一式と複数選択式、持ち込み不可
- Pearson VUE のオンライン監督付きか、テストセンターで受ける
- 合格は 100〜1,000 の尺度で 720 以上（4試験とも同じ）
- 有効期間は12か月。期限内なら Partner Academy 上の監督なしの評価で**無料で更新**できる。失効したら全額で受け直し
- 不合格のあとの待機は 14日 → 30日 → 90日。同じ試験は12か月で4回まで。再受験も受験料は全額
- パートナー階層による割引あり（Select / Preferred / Global Premier は50%、Global Premier は2026年12月末まで100%）

Associate は CPN の階層の評価には数えられない、とも明記されている。

## Architect – Foundations が「運用の判断」そのものだった

Architect – Foundations は、6つの業務場面から4つがランダムに出て、場面ごとに問題が続く形式になっている。場面は、顧客サポートのエージェント、Claude Code での開発、複数エージェントの調査システム、開発者の生産性ツール、CI/CD への Claude Code の組み込み、文書からの構造化データ抽出の6つ。

出題分野と比率はこう書かれている。

| 分野 | 比率 |
|---|---|
| エージェントの設計と連携（Agentic Architecture & Orchestration） | 27% |
| Claude Code の設定とワークフロー | 20% |
| プロンプトと構造化出力 | 20% |
| ツール設計と MCP 連携 | 18% |
| コンテキスト管理と信頼性 | 15% |

試験ガイドには分野ごとに「何を判断できるか」が並んでいる。読んでいて、手元の自動化で一度は踏んだものが多かった。いくつか、自分の運用に引き寄せて書いておく。

### 「プロンプトで頼む」と「仕組みで止める」の区別

ガイドには、確実に守らせたいルールは hooks や前提条件のゲートのような**プログラムで強制する仕組み**に寄せる、という判断が繰り返し出てくる。プロンプトに「〜しないこと」と書くのは、守られる確率を上げるだけで保証ではない。

自分の運用でも、公開前の事実チェックや、送信前の文面チェックは「AI に気をつけてもらう」ではなく、関門の関数を通らないと先に進めない形にしている。試験ではこの区別そのものが問われる。

### サブエージェントは親の会話を引き継がない

指揮役のエージェントがサブエージェントに仕事を渡すとき、**サブエージェントは指揮役の文脈を自動では受け取らない**。必要な情報はプロンプトに明示して渡す、という点がガイドに書かれている。調査を分担させるときに範囲を重ならないように切る、結果は指揮役を通して集める、といった設計も出題範囲に入っている。

### ツールを渡しすぎると選び間違える

エージェントに渡すツールが多すぎると選択の精度が落ちる、役割に必要なツールだけを渡す、ツールの説明文で用途の違いをはっきり書く。MCP については、チームで共有するものはプロジェクトの `.mcp.json`、個人の実験用はユーザー側の設定に置く、という置き場所の使い分けも出てくる。

### CLAUDE.md の階層と計画モード

Claude Code の分野では、CLAUDE.md の階層（ユーザー / プロジェクト / ディレクトリ）、カスタムのスラッシュコマンドと Skills、パスごとのルール、**計画モードと直接実行をどう使い分けるか**、CI への組み込みが並ぶ。

### 長い作業でのコンテキスト

コンテキスト管理の分野は、長い会話で重要な情報を落とさないこと、人に引き継ぐ判断、複数エージェントでのエラーの伝え方、全体の正答率が高くても特定の種類で崩れていないかを見ること、などが並ぶ。

## ほかの3つの重心

- **Associate**：いちばん重いのは「出力の評価と検証」21%。ハルシネーションに気づく、事実を確かめる、人の確認が必要な場面を判断する。開発者向けではないが、業務部門に Claude を広げるときの共通言語にはなりそう
- **Developer**：「アプリケーションと連携」が 33.1%。Messages API の仕組み（ストリーミング、画像、思考、キャッシュ、Batch API の使いどころ）とアプリ設計、CLAUDE.md や settings.json の管理まで含む。推奨経験は開発1〜5年と LLM の実務6か月以上
- **Architect – Professional**：「連携」19%、「解決策の設計」17%、「評価・テスト・最適化」16%。RAG の分割と索引、認証・認可の穴、GDPR などの規制、関係者との合意形成まで入る。推奨はシステム設計3年以上

## 受ける前に確かめること

1. **自社が CPN に加盟しているか。** 加盟していなければ受験できない。会社のドメインを登録に足すのは、パートナーサポートへの連絡から通常7〜10日
2. **言語。** 公式 FAQ は10月16日時点で「試験と対策教材は英語のみ。監督付き試験ではブラウザの翻訳ツールは使えない」。日本語受験の告知との食い違いは、申込画面で確かめる
3. **予約の変更は24時間前まで。** それより後の変更や欠席は受験料が戻らない

加盟していない組織の人は、誰でも受けられる公開コース（Anthropic Academy）がある。ただし、その修了証は認定資格とは別物になる。

数字はすべて 2026年10月16日に、Anthropic Partner Academy の認定ページ・FAQ・受験資格のページと、各試験の Exam Guide（Version 1.0・2026年7月）で確かめたもの。条件は変わることがあるので、申し込む前に最新の案内を確認してほしい。
